# World Map — процедурный мир, чекпоинты и карта с туманом войны

Изолированная фича (по workflow механик): своя сцена, F6-окно, конфиг. В gameplay-корабль ещё
**не интегрирована** — интеграция отдельным шагом после проверки в сцене.

## Как запустить

1. `RumOverboard ▸ World ▸ Build World Map Scene` — собирает `Assets/Scenes/WorldMapScene.unity`
   (песочница корабля + объект `World` с `NetworkWorld` + `WorldDebugWindow`), создаёт при необходимости
   `Assets/Source/Configs/FeatureScenes/WorldGenConfig.asset` и материалы в
   `Assets/Source/Environment/Materials/World`.
   `RumOverboard ▸ World ▸ Relink World Config` — заново привязать конфиг и материалы к `NetworkWorld`
   без пересборки сцены (без привязки мир строился на дефолтном конфиге, а в билде падал без шейдеров).
2. Play. Хост генерирует мир по случайному seed, корабль появляется **пришвартованным** у пирса
   стартового острова.
3. Через главное меню (`Boot`, см. `Frontend.md`) сцена запускается как рейс: seed берётся из
   рейса, прогресс сохраняется в `persistentDataPath/Voyages`, загруженный рейс стартует у причала
   последнего достигнутого чекпоинта (`NetworkWorld.StartCheckpoint`).

## Устройство мира

- **Маршрут**: `ClusterCount + 1` островов-чекпоинтов, между ними — кластеры океана (ноги маршрута).
  Сложность кластера `cfg.Difficulty(k)` (кривая `DifficultyCurve`) растёт к концу.
- **Гавань** каждого острова: пирс, два кнехта, причал (berth), точка подхода (approach), маяк.
  Гавань смотрит на ногу, по которой к острову приходят.
- **Безопасный фарватер** в каждом кластере всегда проходим (прокопан до `ChannelMinDepth`): выход из
  гавани радиально за пределы рифов острова, изгибы (их число и амплитуда растут со сложностью),
  обход всех островов-чекпоинтов.
- **Опасности** по сложности: камни, рифы, мели; узости из скал (`NarrowsFrom`, `SecondNarrowsFrom`),
  риф перед гаванью (`ApproachReefFrom`), скалы у входа в гавань (`ApproachCliffsFrom`).
- **Море и ветер** по кластеру, где находится корабль: `SeaStates` (Calm → Storm) и масштаб ветра
  `WindScaleEasy..Hard`.
- Генерация **детерминирована**: по сети реплицируются только seed/ветер/прогресс/швартовка
  (`NetworkWorld`); каждый пир строит мир сам, контрольная сумма раскладки сверяется с хостом.

Код: `Assets/Source/Scripts/Gameplay/World/`
- `Generation/` — `WorldLayoutGenerator` (раскладка), `WorldLayout` (SDF-высоты, фичи, выемки), шум/рандом.
- `Building/WorldGeometryBuilder` — чанки рельефа (меш + текстура + коллайдеры на мелководье), пирсы, маяки.
- `Map/` — `WorldMapPainter` (картинка-карта + туман), `ChartTable` (стол с картой на палубе), `ChartViewer`.
- `Mooring/` — кнехты (`MooringBollard`) и тросы (`MooringLineView`).
- `NetworkWorld` — агрегатор фичи: сеть, прогресс, швартовка, телепорт, окружение кластера.
- `WorldDebugWindow` — F6.

## Карта и туман войны

- Карта рисуется при генерации (бумага, рельеф, отмели, рифы, компас, масштаб).
- В начале открыта только стартовая гавань и нога до **первого** чекпоинта (отмечен красным ✗).
- Корабль входит в радиус `HarborReachRadius` вокруг причала следующего острова → `Reached++`,
  открывается следующая нога. Пройденные острова помечаются ✓.
- На палубе стоит **штурманский стол**: подойти, **E** — карта крупно (колесо — зум, ЛКМ — двигать),
  **E/Esc** — закрыть.
- На карте — **корабль**: на столе маленький силуэт (`ChartTable.Marker`), в крупном виде иконка,
  повёрнутая по курсу, и пунктир до следующего острова. Слева — **судовой журнал**: курс и румб,
  скорость (уз), ветер (сила, откуда, курс относительно ветра, галс), «паруса ловят ветер N%» и по
  каждому парусу (тяга + угол рея, см. ShipSandbox.md → виджет), руль, расстояние и пеленг до
  следующего острова и на сколько отвернуть. Данные — тот же `ShipStatusSnapshot`, что у виджета.

## Швартовка

- На старте корабль пришвартован (пружинные тросы к кнехтам, держат только на растяжение).
- **E у кнехта на пирсе** — отдать швартовы / закрепить (только у своей гавани и рядом с причалом).

## Debug-окно (F6)

Статус (seed, тайминги, прогресс), превью карты с маркером корабля, «показать всё»/«фарватеры»,
экспорт PNG; для хоста — новый seed, телепорт к подходу/причалу любого острова, Reached ±, сброс
прогресса, отдать/закрепить швартовы; слайдеры генерации → «Rebuild locally», **Reset from config**,
**Save to config**.

## Автотесты (batch)

```
# генератор: 20 seed'ов — фарватер везде глубокий, причал на глубине, сложность растёт,
# детерминизм, туман открывается монотонно. PNG карт → Logs/WorldPreview
Unity -batchmode -projectPath . -executeMethod RumOverboard.EditorTools.World.WorldGenSelfTest.Run -worldSeeds 20

# play-mode: мир построен, корабль пришвартован и держится, стол с картой (маркер корабля на месте и
# по курсу, журнал читает корабль), кнехты (E),
# прибытие на чекпоинт 1 открывает карту, регенерация. Скриншоты (опц.) → -worldShots <dir>
Unity -batchmode -projectPath . -executeMethod RumOverboard.EditorTools.World.WorldMapSceneSetup.RunSmoke -worldSmoke
```

Код возврата 0 = всё прошло; отчёт в логе (`[WorldGenSelfTest]`, `[WorldSmoke]`).

## Заметки

- Диск океана в этой сцене расширен до 2600 м (`meshRadius`, 250 колец — та же плотность у корабля),
  дальность камеры 2400 м, чтобы дальние острова стояли в воде.
- Сборка мира синхронная при спавне (~1.3 с в редакторе); при интеграции — экран загрузки или разнесение по кадрам.
- Клиенты не предсказывают физику корабля (как и в песочнице).
